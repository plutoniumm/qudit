Benchmarks ​

All results are wall-clock means over ≥20 runs with warmup, on the same hardware (Apple Silicon M-series). Generated by cd bench && conda run -n qudit python run.py → docs/public/bench.json.

CategoryWhat's measured

Noisy CircuitsDepol / AD / phase-damp — stochastic vs deterministic vs other frameworks

Gradient DescentVQE loop — autograd vs parameter-shift across 6 frameworks
QUBO / QAOAQUBO conversion, QAOA forward pass, ClockSolver loop
MetricsFidelity, entropy, mutual info, trace/Bures distance — scaling with d

Charts use log scale by default. qudit series are shown with solid bold lines; other frameworks use dashed lines. Lower is always better.
