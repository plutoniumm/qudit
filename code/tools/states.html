W ​

Construct the n-qudit W state (single-excitation symmetric state).

Returns ∑i=0n−1|0⋯1i⋯0⟩ (unnormalized) where |0⟩ and |1⟩ are the ground and first-excited levels.

def W(n: int, d: int) -> State

Implementation

def W(n: int, d: int=2) -> State:
    Ket = Basis(d)
    vals = ['0' * i + '1' + '0' * (n - i - 1) for i in range(n)]
    vals = sum([Ket(v) for v in vals])
    return State(vals)

def NOON(n: int, theta: float=0.0) -> State:
    Ket = Basis(n + 1)
    kets = [Ket(0, n), Ket(n, 0)]
    kets = kets[0] + np.exp(1j * n * theta) * kets[1]
    return State(kets)

Dicke ​

Construct an n-qudit Dicke state with k zeros (and n−k ones).

Returns the uniform (unnormalized) superposition over all distinct permutations of k symbols 0 and n−k symbols 1.

def Dicke(n: int, k: int, d: int=2) -> State:
    Ket = Basis(d)
    vals = sum((Ket(''.join(('0' if i in zeros else '1' for i in range(n)))) for zeros in combinations(range(n), k)))
    return State(vals)

Truncated coherent state in a finite (N+1)-dimensional Fock space.

Builds ∑n=0Nαn/n!|n⟩ with a normalization correction from the incomplete gamma function.

Reference at arxiv:1402.1487

def Coherent(N: int, alpha: complex=1.0) -> State:
    Ket = Basis(N + 1)
    a2 = abs(alpha) ** 2
    norm = np.exp(a2) * (1 - g(N + 1, a2) / F(N))
    norm = 1 / np.sqrt(norm)
    vec = sum((alpha ** n / np.sqrt(F(n)) * Ket(n) for n in range(N + 1)))
    return State(norm * vec)
